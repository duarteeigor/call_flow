# CallFlow

CallFlow é uma aplicação web para gerenciamento de chamados de suporte técnico de clientes. O sistema permite que clientes cadastrados abram chamados por conta própria, enquanto usuários autenticados podem gerenciar, criar e acompanhar os chamados de seus clientes através de um painel de controle (dashboard).

O projeto inclui funcionalidades como abertura de chamados pelo cliente, gerenciamento de chamados em aberto, cadastro de novos chamados, visualização de clientes e histórico completo de chamados (abertos e fechados). Todas as rotas administrativas são privadas e exigem login.

---

## Tecnologias utilizadas

- **Next.js** com TypeScript  
- **Tailwind CSS**  
- **React Hook Form** + **Zod** (para validações de formulários)  
- **NextAuth.js** (autenticação via Google)  
- **MongoDB** + **Prisma** (ORM para gerenciamento de dados)  
- **API do Next.js** (backend integrado para requisições)
